Week 1 build notes

  • Provenance is a simulated SHA-256 hash-chain inside Postgres, not a public testnet — described honestly as a private, testnet-ready ledger, surfaced on its own Provenance Ledger screen.
  • Districts: 2–3 real districts from Bhuvan / data.gov.in, chosen for the most visually dramatic land-use change.
  • LLM access is bring-your-own-key, entered in-app and encrypted per session — the same pattern used in the QA-agent and Nova/SemantIQ builds.
  • Change detection is precomputed and cached for the demo districts; the live GeoPandas/Rasterio path exists but isn't the critical path for the scripted demo.
  • Deployment is local-only for a team-scripted live demo — Docker is skipped this week, not required.
